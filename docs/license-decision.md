# 라이선스 결정 초안 — 체크리스트 (결정 주체: 사용자)

> 법률 자문이 아니다. 공개 저장소(ADR-007) 운영에 필요한 결정 항목과 체크리스트만 남긴다.
> 현재 상태: 저장소 public + **LICENSE 파일 없음** = 저작권 전부 보류(기본적으로 복제·2차 이용 비허용).

## 배경 사실 (ADR-007, 2026-08-29)

- 수익화(Travelpayouts 제휴)를 전제로 public 유지 — 수익 자산은 계정·데이터·SEO·무인 운영이며 코드 가시성은 매출 경로가 아니라는 판단.
- 라이선스 미부여는 의도적(복제 합법화 방지). 과거 `require/` 비공개 전환 이력 有.

## 옵션

| 옵션 | 효과 | 비용/리스크 |
|---|---|---|
| A. 현재 유지 (LICENSE 없음) | 복제가합법 아님, 변경 없음 | "퍼블릭인데 라이선스 없음" 경고 표시 지속, 우호적 이용자도 법적으로 못 씀 |
| B. private 전환 | 코드 완전 비공개 | GitHub Actions 무료 한도 축소(공개 리포 무료 분이 사라짐 — ₩0 원칙과 충돌), 스타/포크 이력 정리 |
| C. SOURCE-AVAILABLE 고지 (커스텀 비허용 문구) | 경고 해소·의도 명문화 | 커스텀 문구는 법적 효력 검증 필요(사용자 판단) |
| D. 관대 라이선스 (MIT 등) | 이용 장벽 최소 | 복제 합법화 — ADR-007 전제와 충돌 |

## 체크리스트 (선택 후)

- [ ] 옵션 확정 (권장 논의 순서: A 유지 → C 고지 → B 전환; D는 수익 정착 전 부적합)
- [ ] C 선택 시: LICENSE 파일 초안 검토(법률 단정 없이 표준 문구 참조) → 커밋은 별도 승인
- [ ] B 선택 시: private 전환 전 시크릿 이력 재점검(`npm run lint:secrets` + 과거 커밋 스캔), Actions 분 한도 영향 확인
- [ ] README "제품 요구사항: 비공개" 문구와 정합 재확인
