# 자율 개발 안전 클래스 화이트리스트 (ADR-009 운영 가드)

무인 개선 루프가 **사람 승인 없이** 커밋→push→CI→자동 배포→프로덕션 실측까지 할 수 있는
변경 클래스는 아래 5종뿐이다. 이 목록 밖은 전부 승인 대기(패치/PR+승인 메모)로만 진행한다.

## 안전 클래스 (자율 종단 허용)

1. **계약 테스트** — 기존 동작을 고정하는 테스트 추가·강화(`tests/*-contract.mjs`).
2. **가드** — 데이터 품질·신선도·폴백·표시 규칙을 지키는 방어 코드(+그 계약 테스트).
3. **버그픽스** — 재현 수단이 있는 결함의 근본 원인 수정(증상 은폐 금지).
4. **신선도 재계산** — min(live offers) 계약·스테일 스윕·조인 비율 등 데이터 세대 정합화.
5. **합성 체크·운영 관측** — 실패-only 알림 배선·프로브·역할 분리 문서화.

## 비안전 클래스 (승인 필수)

- UI 카피·레이아웃·컴포넌트 표시 변경(가드가 카피를 바꾸게 되면 비안전으로 승격)
- 인프라: 워크플로 스케줄·env 값 주입·시크릿·새 의존성·DB 스키마(DDL)
- 외부 값(매니페스트 재구성·API 토큰·계정 생성)
- 위 항목은 브랜치 PR 또는 패치+승인 메모로만 남긴다.

## 확대 금지

이 화이트리스트의 확대는 **사람 승인 + `tests/autonomy-policy-contract.mjs` 갱신**을
동반해야만 유효하다 — 루프가 조용히(문서·프롬프트만으로) 범위를 넓히는 것을 계약 테스트로 봉쇄한다.

## 배포 롤백 한 줄

자율 커밋 배포 후 이상 징후(합성 체크 실패·프로브 503)가 확인되면:
**Vercel 대시보드 → Deployments → 직전 안정 배포 "Promote to Production"** (CLI 접근 계정이 아니어도 대시보드로 즉시 가능).
Promote 후 원인 커밋은 revert 1커밋로 뒤따른다.

## 커밋/로그 시크릿 가드

`npm run lint:secrets`(`scripts/scan-secrets.mjs`)이 커밋 메시지·소스 트리를 스캔하고
CI(ci.yml)가 매 push/PR에 실행한다 — 걸리면 CI 실패. 실 시크릿 발견 시 폐기(회전)가 커밋 제거보다 우선이다.
